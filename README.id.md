### 🤖 Asisten Kecerdasan Buatan & Penelitian
Asisten kecerdasan buatan serbaguna, mesin penjawab, dan alat penelitian.

- [ChatGPT](https://chatgpt.com/) — Asisten kecerdasan buatan untuk menulis, analisis, pembelajaran, pengodean, dan pekerjaan yang berkaitan dengan berkas.  
- [Claude](https://claude.ai/) — Asisten kecerdasan buatan yang cocok untuk menulis, bernalar, analisis dokumen, dan pengodean.  
- [DeepSeek](https://www.deepseek.com/) — Model obrolan dan penalaran kecerdasan buatan untuk pertanyaan umum dan tugas teknis.  
- [Google Gemini](https://gemini.google.com/) — Asisten kecerdasan buatan dari Google untuk penelitian, menulis, curah gagasan, dan tugas dalam ekosistem Google.  
- [Hugging Face](https://huggingface.co/) — Pusat untuk menemukan, berbagi, dan menjalankan model pembelajaran mesin serta set data.  
- [Microsoft Copilot](https://copilot.microsoft.com/) — Asisten kecerdasan buatan untuk riset web, pertanyaan sehari-hari, dan alur kerja Microsoft.  
- [Mistral Le Chat](https://chat.mistral.ai/) — Asisten obrolan kecerdasan buatan dari Mistral untuk menulis, analisis, dan penelitian.  
- [NotebookLM](https://notebooklm.google.com/) — Asisten penelitian yang menjawab pertanyaan menggunakan sumber yang Anda sediakan.  
- [Perplexity](https://www.perplexity.ai/) — Mesin penjawab yang menelusuri web dan memberikan respons yang dilengkapi dengan tautan ke sumber aslinya.  
- [Poe](https://poe.com/) — Platform untuk menggunakan berbagai model kecerdasan buatan dan bot buatan komunitas di satu tempat.

### 🧪 Pengembangan Antarmuka Pemrograman Aplikasi (API), Pengujian & Penjaminan Mutu (QA)
Klien antarmuka pemrograman aplikasi (API), pengujian otomatis, pengujian peramban web, dan pemeriksaan kualitas web.

- [BrowserStack](https://www.browserstack.com/) — Uji situs web dan aplikasi di seluruh peramban web, sistem operasi, dan perangkat nyata.  
- [Cypress](https://www.cypress.io/) — Kerangka kerja pengujian untuk end-to-end aplikasi web dan pengujian komponen.  
- [Insomnia](https://insomnia.rest/) — Klien antarmuka pemrograman aplikasi (API) untuk membangun dan menguji permintaan REST, GraphQL, dan lainnya.  
- [Jest](https://jestjs.io/) — Kerangka kerja pengujian JavaScript yang umum digunakan untuk pengujian unit dan integrasi.  
- [JUnit](https://junit.org/junit5/) — Kerangka kerja pengujian untuk aplikasi Java.  
- [Lighthouse](https://developer.chrome.com/docs/lighthouse/overview/) — Audit kinerja web, aksesibilitas, pengoptimalan mesin pencari (SEO), dan praktik terbaik.  
- [PageSpeed Insights](https://pagespeed.web.dev/) — Ukur kinerja halaman web dan dapatkan rekomendasi pengoptimalan.  
- [Playwright](https://playwright.dev/) — Otomatiskan pengujian end-to-end di seluruh mesin peramban web utama.  
- [Postman](https://www.postman.com/) — Desain, uji, dokumentasikan, dan berkolaborasi pada antarmuka pemrograman aplikasi (API).  
- [pytest](https://pytest.org/) — Kerangka kerja pengujian Python yang fleksibel dengan ekosistem plugin yang kaya.  
- [Selenium](https://www.selenium.dev/) — Alat otomatisasi peramban web untuk menguji aplikasi web.  
- [Stoplight](https://stoplight.io/) — Desain, dokumentasikan, dan kelola antarmuka pemrograman aplikasi (API) menggunakan alur kerja yang mengutamakan API.  
- [Swagger Editor](https://editor.swagger.io/) — Buat dan validasi spesifikasi antarmuka pemrograman aplikasi (API) OpenAPI dalam penyunting berbasis peramban web.  
- [Vitest](https://vitest.dev/) — Kerangka kerja pengujian cepat yang dirancang untuk proyek JavaScript dan Vite modern.  
- [WebPageTest](https://www.webpagetest.org/) — Jalankan pengujian kinerja situs web terperinci dari berbagai lokasi dan perangkat.

### 💾 Basis Data & Rekayasa Data
Basis data, jalur pipa data (data pipelines), alat kueri, dan platform rekayasa data.

- [Apache Airflow](https://airflow.apache.org/) — Tulis, jadwalkan, dan pantau alur kerja data menggunakan Python.  
- [Apache Spark](https://spark.apache.org/) — Mesin terdistribusi untuk pemrosesan data dan analitik berskala besar.  
- [Appwrite](https://appwrite.io/) — Platform backend sumber terbuka untuk membangun aplikasi web, seluler, dan Flutter.  
- [Databricks](https://www.databricks.com/) — Platform untuk rekayasa data, analitik, dan alur kerja pembelajaran mesin.  
- [DBeaver](https://dbeaver.io/) — Klien basis data universal untuk menghubungkan dan mengelola banyak sistem basis data.  
- [dbt](https://www.getdbt.com/) — Transformasikan data dalam gudang data menggunakan SQL, pengujian, dan alur kerja dengan sistem kontrol versi.  
- [Firebase](https://firebase.google.com/) — Platform pengembangan aplikasi Google dengan layanan backend, autentikasi, analitik, dan hosting.  
- [Google BigQuery](https://cloud.google.com/bigquery) — Gudang data terkelola untuk analitik SQL berskala besar.  
- [MongoDB](https://www.mongodb.com/) — Basis data berorientasi dokumen untuk model data aplikasi yang fleksibel.  
- [MySQL](https://www.mysql.com/) — Basis data relasional yang banyak digunakan untuk situs web dan aplikasi.  
- [Neon](https://neon.tech/) — Platform PostgreSQL nirserver dengan percabangan dan komputasi yang dapat diskalakan.  
- [PostgreSQL](https://www.postgresql.org/) — Sistem basis data relasional sumber terbuka yang tangguh.  
- [Redis](https://redis.io/) — Penyimpanan data dalam memori yang digunakan untuk singgahan (caching), pesan, dan akses data yang cepat.  
- [Snowflake](https://www.snowflake.com/) — Platform data awan untuk pergudangan data, rekayasa, dan analitik.  
- [SQLite](https://www.sqlite.org/) — Basis data SQL ringan tanpa peladen (serverless) yang disematkan dalam aplikasi.  
- [Supabase](https://supabase.com/) — Platform pengembang yang dibangun dengan dasar PostgreSQL yang mencakup autentikasi, penyimpanan, dan antarmuka pemrograman aplikasi (API).

### 📖 Cara Menambah atau Mengubah Alat
Daftar alat disimpan di dua file JSON, satu untuk setiap bahasa. Kedua file README dibuat otomatis dari file tersebut, jadi jangan mengedit README secara manual: perubahan Anda akan tertimpa.

**File utama**

```text
.
├── data/
│   ├── tools.en.json     # Daftar alat (Inggris)
│   └── tools.id.json     # Daftar alat (Indonesia)
├── scripts/
│   └── build_readme.py   # Membuat kedua README dari data/
├── README.md             # README Inggris (dibuat otomatis)
└── README.id.md          # README Indonesia (dibuat otomatis)
```

**1. Tambahkan alat ke file Inggris.** Buka `data/tools.en.json`, cari kategorinya, lalu sisipkan entri sesuai urutan abjad:

```json
{
  "name": "Example Tool",
  "url": "https://example.com/",
  "description": "A short sentence that ends with a period."
}
```

**2. Tambahkan alat yang sama ke file Indonesia.** Gunakan `name` dan `url` yang sama pada posisi yang sama di `data/tools.id.json`, lalu tulis `description` dalam bahasa Indonesia:

```json
{
  "name": "Example Tool",
  "url": "https://example.com/",
  "description": "Satu kalimat singkat yang diakhiri titik."
}
```

**3. Buat ulang README.** Dibutuhkan Python 3.8 atau lebih baru; tidak ada yang perlu dipasang:

```bash
python3 scripts/build_readme.py
```

**4. Commit** kedua file JSON dan kedua file README bersamaan.

Untuk mengubah atau menghapus alat, ubah atau hapus entrinya di kedua file JSON, lalu jalankan skrip lagi. Untuk menambah kategori, tambahkan objek dengan `id` unik, `name`, `icon` (satu emoji yang belum dipakai kategori lain), `description`, dan daftar `tools` ke kedua file pada posisi yang sama.

**Yang ditolak skrip**

- kategori, alat, nama, URL, atau urutan yang berbeda antara kedua file
- `icon` yang hilang, berbeda antar bahasa, atau dipakai dua kategori
- URL yang muncul dua kali atau tidak diawali `https://`
- nama atau deskripsi yang kosong, atau yang mengandung karakter Markdown seperti `*`, `_`, `[`, `]`, `<`, `>`, `|`

Jika data ditolak, skrip menampilkan semua masalah dan tidak menulis apa pun.

**Cek apakah README sudah terbaru**

```bash
python3 scripts/build_readme.py --check
```

Perintah ini menampilkan `README files are up to date.` dan berhenti dengan kode 0. Jika ada README yang usang, skrip menyebut nama filenya dan berhenti dengan kode 1, sehingga bisa dipakai juga di CI.
